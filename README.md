# TifotoTiTrovo — GitHub build

Carica TUTTO il contenuto di questa cartella in un repository GitHub.

Poi:
1. GitHub → Actions
2. "Build TifotoTiTrovo APK"
3. Run workflow
4. Aspetta la build
5. Apri la build completata
6. Nella sezione Artifacts scarica "TifotoTiTrovo-debug"
7. Estrai e installa l'APK sul tablet.

Il primo test usa Google ML Kit Image Labeling on-device, senza API OpenAI.
